# Sunline Trophy Desk

An offline desk for the 55 PlayStation 5 trophies of Grand Theft Auto VI. The tracker keeps official names, descriptions, and grades, saves progress in the browser, and opens a cited walkthrough for each trophy. The roadmap is six stages to the platinum. The missables table marks what can lock, what to watch, and what is safe after the credits. The sources page names every public page the desk was written from.

## Run it

```
node serve.ts
```

Then open the local address serve.ts prints. Repeatable views use query parameters, for example `?demo=1&tab=tracker&trophy=strangers-and-freaks`. Tabs: `tracker`, `roadmap`, `missables`, `sources`.
